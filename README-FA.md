## 📖 معرفی

__مترجم صوتی گپ‌جی‌پی‌تی__ یک برنامه دسکتاپ پایتونی است که صدا را از میکروفون شما ضبط می‌کند، با استفاده از مدل‌های وایسپر (Whisper) سازگار با OpenAI آن را به متن تبدیل می‌کند و در صورت تمایل، متن رونویسی‌شده را به یک مدل زبانی بزرگ (LLM) ارسال می‌کند تا متن تمیزتر و ویراسته‌تری تولید شود.

این برنامه دارای یک رابط کاربری گرافیکی مدرن با تم تیره، مدیریت جلسات ضبط، و یکپارچگی کامل با [API گپ‌جی‌پی‌تی](https://gapgpt.app) است.

## ⚙️ پیکربندی

### تنظیم کلید API

فایل `.env` را در ریشه پروژه بسازید یا ویرایش کنید:

```env
GAPGPT_API_KEY="کلید-ایپی-خود-را-اینجا-بگذارید"
GAPGPT_BASE_URL="https://api.gapgpt.app/v1"
GAPGPT_TRANSCRIPTION_MODEL="gapgpt/whisper-1"
GAPGPT_ARTICULATION_MODEL="gapgpt-qwen-3.6"
ENABLE_ARTICULATION="true"
AUDIO_SAMPLE_RATE="16000"
AUDIO_CHANNELS="1"
```

> __هشدار امنیتی:__ هرگز فایل `.env` خود را با یک کلید API واقعی در یک مخزن عمومی commit نکنید.

### گزینه‌های پیکربندی

| تنظیم | پیش‌فرض | توضیحات | |---|---|---| | `GAPGPT_API_KEY` | *(اجباری)* | کلید احراز هویت API گپ‌جی‌پی‌تی شما | | `GAPGPT_BASE_URL` | `https://api.gapgpt.app/v1` | آدرس پایه endpoint های API | | `GAPGPT_TRANSCRIPTION_MODEL` | `gapgpt/whisper-1` | مدل وایسپر برای تبدیل گفتار به متن | | `GAPGPT_ARTICULATION_MODEL` | `gapgpt-qwen-3.6` | مدل LLM برای بهبود و ویرایش متن | | `ENABLE_ARTICULATION` | `true` | اجرای بهبود متن توسط LLM پس از رونویسی | | `AUDIO_SAMPLE_RATE` | `16000` | نرخ نمونه‌برداری میکروفون (Hz) | | `AUDIO_CHANNELS` | `1` | تعداد کانال‌های صدا (۱ = مونو، ۲ = استریو) |

> 💡 تمام تنظیمات را می‌توانید مستقیماً از طریق پنل __Settings__ درون برنامه نیز تغییر دهید.

## 🚀 نحوه استفاده

### راه‌اندازی برنامه (ویندوز)

روی فایل `run_voice_converter.bat` دابل‌کلیک کنید یا در ترمینال اجرا کنید:

```bash
.\run_voice_converter.bat
```

### راه‌اندازی دستی

```bash
venv\Scripts\activate.bat
python gapgpt_transcriber.py
```

### راهنمای گام‌به‌گام

۱. __کلید API خود را وارد کنید__ — در پنل Settings یا فایل `.env` ۲. __روی "Start Recording" کلیک کنید__ — به میکروفون صحبت کنید ۳. __روی "Stop" کلیک کنید__ — رونویسی به‌طور خودکار شروع می‌شود ۴. __اختیاری:__ گزینه "Enable Articulation" را فعال کنید برای بهبود متن توسط LLM ۵. __بررسی رونویسی‌ها__ — رونویسی‌ها در پنل پایین نمایش داده می‌شوند ۶. __کپی یا حذف__ رونویسی‌های فردی با دکمه‌های هر کارت ۷. __"Clear All"__ — حذف تمام رونویسی‌ها ذخیره‌شده

## 🔌 endpoint های API استفاده‌شده

برنامه با API گپ‌جی‌پی‌تی (سازگار با OpenAI) ارتباط برقرار می‌کند:

| endpoint | روش | هدف | |---|---|---| | `/audio/transcriptions` | `POST` | تبدیل فایل صوتی به متن | | `/chat/completions` | `POST` | ارسال متن به LLM برای بهبود |

### نمونه درخواست — رونویسی

```bash
POST https://api.gapgpt.app/v1/audio/transcriptions
Headers:
  Authorization: Bearer <API_KEY>
  Content-Type: multipart/form-data

Body:
  model: "gapgpt/whisper-1"
  file: recording_20250101_120000.wav
  language: "fa"
```

### نمونه درخواست — بهبود متن

```bash
POST https://api.gapgpt.app/v1/chat/completions
Headers:
  Authorization: Bearer <API_KEY>
  Content-Type: application/json

Body:
{
  "model": "gapgpt-qwen-3.6",
  "messages": [
    {
      "role": "system",
      "content": "You are a helpful assistant. Your task is to refine transcribed speech text. Produce grammatically correct, well-formatted text while preserving the original meaning. Keep it concise and natural."
    },
    {
      "role": "user",
      "content": "<raw_transcript_text>"
    }
  ]
}
```

## 🔧 جزئیات فنی

### خط لوله ضبط

```javascript
میکروفون → sounddevice → آرایه‌های numpy → صف → فایل wav → API
```

۱. صدا با `sounddevice.InputStream` در نرخ نمونه‌برداری تنظیم‌شده ضبط می‌شود ۲. هر قطعه صدا در یک `queue.Queue` غیررقابتی قرار می‌گیرد ۳. رشته اصلی صف را خالی کرده و قطعات را در یک لیست جمع می‌کند ۴. در زمان توقف، قطعات به هم متصل شده و به صورت فایل `.wav` ذخیره می‌شوند ۵. فایل `.wav` به API رونویسی آپلود می‌شود

### فرآیند رونویسی و بهبود

```javascript
توقف ضبط → ذخیره WAV → رونویسی (Whisper) → [بهبود (LLM)؟] → ذخیره و نمایش
```

- __رونویسی__ به‌صورت synchronous اجرا می‌شود — تا پاسخ API منتظر می‌ماند
- __بهبود__ در یک رشته جداگانه اجرا می‌شود — رابط کاربری را مسدود نمی‌کند
- هر دو مرحله را می‌توان در میانه فرآیند لغو کرد

### الگوی نام‌گذاری فایل‌ها

| نوع | الگو | نمونه | |---|---|---| | ضبط‌های صوتی | `recording_YYYYMMDD_HHMMSS.wav` | `recording_20250101_120000.wav` | | رونویسی‌ها | `transcript_YYYYMMDD_HHMMSS.txt` | `transcript_20250101_120000.txt` |

## 🐛 رفع اشکال

| مشکل | راه‌حل | |---|---| | `"Failed to start recording"` | بررسی اتصال میکروفون و عدم استفاده برنامه دیگر | | `"No audio captured"` | کاهش `AUDIO_SAMPLE_RATE` یا بررسی مجوزهای میکروفون | | `"Missing API Key"` | وارد کردن کلید API در پنل Settings یا فایل `.env` | | __خطاهای خاموش API__ | بررسی بخش error در پایین برنامه | | رونویسی کار می‌کند اما بهبود نه | بررسی `ENABLE_ARTICULATION=true` و صحت نام مدل بهبود |
